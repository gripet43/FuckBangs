# 干掉刘海 · 用户手册

版本 1.0.0 ｜ 适用于 macOS 13 Ventura 及以上

---

## 这是什么

MacBook 屏幕顶部的黑色缺口（刘海）是摄像头开孔，物理上无法改变。这个工具的做法是：在菜单栏那一层下面垫一条纯黑，让缺口和四周的黑连成一条完整的黑色顶边，视觉上"刘海被干掉，而且没留下疤"。

壁纸不会被改动，随时可以一键关掉。

---

## 系统要求

| 项目 | 要求 |
|---|---|
| 系统 | macOS 13 Ventura 或更高 |
| 芯片 | Apple 芯片（M1 及以后）或 Intel，同一安装包 |
| 屏幕 | 带刘海的 MacBook（14/16 寸 MacBook Pro，M2 起的 MacBook Air） |

没有刘海的 Mac 也能安装，只是不会产生任何效果，主界面会提示"当前显示器没有刘海"。

## 安装

1. 双击 `干掉刘海-1.0.0.dmg`
2. 把「干掉刘海」拖进旁边的 Applications 文件夹
3. 打开「启动台」或「应用程序」里的图标

**首次打开被系统拦下怎么办（重要）**

本版本使用本地签名，未经过 Apple 公证。第一次打开时系统会弹出「无法打开，因为 Apple 无法验证此 App 是否包含恶意软件」。

处理步骤：

1. 先在「应用程序」里双击一次图标，看到提示后点「完成」（不要点「移到废纸篓」）
2. 打开「系统设置」→「隐私与安全性」，向下滚动到「安全性」
3. 找到提示「已阻止使用"干掉刘海"，因为 Apple 无法验证…」，点「仍要打开」
4. 输入密码或使用触控 ID，再在确认框里点「打开」

之后这个 App 会被记为例外，以后双击即可正常打开。

> 旧教程里那种「右键 → 打开 → 再点打开」的绕过方式，苹果已经在 macOS 15 Sequoia 中移除了，现在按了也不会出现「打开」按钮。只能用上面这条路。
>
> 「仍要打开」按钮只在打开失败后的一小时内出现。如果没看到，重新双击一次再回来。

## 三种打开设置的方式

| 入口 | 操作 | 结果 |
|---|---|---|
| 状态栏图标 | 左键单击 | 弹出快捷面板，可直接切换开关 |
| 状态栏图标 | 右键单击 | 菜单：打开主界面 / 停用 / 退出 |
| 程序坞图标 | 单击 | 打开主界面 |

状态栏图标长得像一块屏幕顶部的缺口。找不到的话，看菜单栏最右侧、时钟左边。

## 六个开关

| 开关 | 作用 | 默认 |
|---|---|---|
| 干掉刘海 | 总开关，关掉后黑边立即消失 | 开 |
| 模拟屏幕圆角 | 只给 MacBook 自带屏加圆角，外接屏保持直角；需先开启「干掉刘海」 | 开 |
| 显示在状态栏 | 是否在菜单栏显示图标 | 开 |
| 显示在程序坞 | 是否在程序坞显示图标 | 开 |
| 全屏时自动隐藏 | 全屏看视频、玩游戏时自动让位 | 开 |
| 登录时自动启动 | 开机后自动运行 | 关 |

**关于两个入口开关**：如果把它们都关掉，应用就没有任何可见入口了。为避免你把自己锁在外面：

- 关掉最后一个入口时会弹确认框
- 真的都关掉后，用 Spotlight（⌘ + 空格）搜索"刘海"或"干掉刘海"，打开即回到主界面

## 模拟屏幕圆角

把**正文区域**做成一整块圆角矩形：状态栏保持整条黑色、四角是方的，它压在上方；下面的桌面内容则四角同半径收圆，看起来像一张放在黑色台面上的卡片。

**它是「干掉刘海」的下属功能**：总开关关掉时，这一项会变灰、不可设置，圆角也会一起消失。因为圆角的前提是顶部先被处理成一条完整的黑，否则"卡片"没有台面可放。

- **只作用于 MacBook 自带屏**。外接显示器绝大多数是直角边框，保持直角才自然，所以不做处理
- **只画在桌面层**。圆角垫在壁纸之上、所有窗口之下，因此全屏应用、视频、游戏完全不受影响
- **四角同半径**：上两角与下两角用的是同一条弧线，不会出现"上面小、下面大"
- **半径可调**：主界面拖动滑块，8–48 点之间，默认 40

---

## 卸载

1. 点状态栏图标 → 右键 → 退出（或在主界面点「退出」）
2. 把「干掉刘海」从「应用程序」拖到废纸篓
3. 可选：清掉残留偏好

```bash
defaults delete com.gripet.notchblack
```

如果不做第 3 步，下次重装会沿用上次的开关状态。

## 已知行为

- **截图会带上黑边**：黑边是真实窗口，整屏截图时会拍进去。刘海本身在截图里不存在，所以截图看起来会比实际多一条黑。局部截图（⌘⇧4 选区域）不受影响。
- **只对带刘海的屏生效**：外接显示器不会被画黑边。
- **切换分辨率后会自动适配**：如果把内置屏切到"刘海下方"分辨率档，黑边会自动让位，切回来再自动恢复。
- **不接管鼠标**：黑边不接收点击，菜单栏照常可以点。
