# 隐私说明与许可

## 一句话

不联网、不上传、不采集。所有数据只存在你这台 Mac 上。

## 具体做了什么

| 项目 | 说明 |
|---|---|
| 网络访问 | 无。应用不包含任何网络请求代码，不访问互联网或局域网 |
| 数据上传 | 无。不采集任何使用数据、崩溃日志或设备信息 |
| 屏幕内容读取 | 不读取。仅通过系统接口获取"屏幕尺寸、刘海区域高度、是否存在全屏窗口"这类结构信息，不获取任何画面内容 |
| 键盘/鼠标监听 | 无。不申请辅助功能权限，不监听全局输入 |
| 摄像头/麦克风 | 无。刘海里的摄像头只由系统使用，应用不访问 |
| 本地存储 | 仅一处：`~/Library/Preferences/com.gripet.notchblack.plist`，保存五个开关状态和主界面位置 |

## 文件读写

- 读取：无额外文件读取
- 写入：仅上面提到的偏好设置文件

## 权限说明

应用不需要任何系统权限。若在「系统设置 → 隐私与安全性」中看到它请求权限，可以拒绝，不影响使用。

「登录时自动启动」使用系统提供的 `SMAppService` 接口，不通过辅助功能权限实现，也不会在后台常驻额外进程。

## 卸载后

删除应用后，偏好设置仍会保留在本地。需要彻底清除可执行：

```bash
defaults delete com.gripet.notchblack
```

## 关于"未签名"的说明

发行包使用本地签名（ad-hoc），未购买 Apple 开发者账号，因此未做 Developer ID 签名与公证。这不影响功能，但首次打开需要手动允许一次，步骤见《用户手册》。

如果有人愿意接手发布，用自己的开发者账号重新签名并公证即可消除这个提示，代码本身不需要改动。
