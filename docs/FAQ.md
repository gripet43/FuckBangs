# 常见问题

## 刘海还在屏幕上吗？

在。刘海是摄像头开孔，是硬件，任何软件都改不了它的形状。本工具做的是视觉处理：把菜单栏那一层变成纯黑，让缺口和周围的黑融成一条完整的黑色顶边，所以你看不到"缺一块"的感觉。

## 为什么全屏看视频时黑边不见了？

这是「全屏时自动隐藏」在起作用。全屏时菜单栏本来就不显示，留着黑边反而会挡住画面，所以会自动让位，退出全屏后自动恢复。不想要这个行为，可以在主界面关掉。

## 外接显示器为什么不生效？

只对带刘海的屏幕生效。外接屏没有缺口，画黑边没有意义，反而会遮住内容。

## 外接显示器为什么没有圆角？

故意的。外接屏绝大多数是直角边框，把屏幕内容裁成圆角反而会露出一圈黑三角，看着别扭。圆角只给 MacBook 自带屏，那里的物理边框本来就是圆的。

## 屏幕圆角会影响全屏应用或游戏吗？

不会。圆角画在桌面层，位于所有窗口之下，全屏应用和游戏会完整覆盖它，四角不会被切掉。这也是它和"压在所有内容之上"的方案最大的区别。

## 屏幕圆角看着不明显？

顶部整条是黑的，圆角要靠"黑色和内容的交界"才能看出来。所以现在黑条本身也跟着圆角收进角落，露出一小条壁纸作为交界——这就是四角弧线的来源。想更明显就把半径调大；如果不想在顶部看到那条浅色弧，把半径调到 24 以下会非常细微。

## 把两个图标都关了，怎么再打开？

用 Spotlight（⌘ + 空格）搜索"刘海"或"干掉刘海"，回车即打开主界面。也可以直接双击「应用程序」里的图标。

关掉最后一个入口时会有确认框提醒，不会毫无征兆地消失。

## 截图里为什么多了一条黑边？

黑边是一个真实的窗口，整屏截图会把它拍进去。而刘海本身是硬件，不在截图数据里，所以截图看起来比肉眼多一条黑。

介意的话可以用区域截图（⌘⇧4 拖选范围），或者临时在快捷面板里关掉"干掉刘海"再截。

## 会影响菜单栏点击吗？

不会。黑边层级在菜单栏之下，并且完全忽略鼠标事件，菜单栏里的图标、菜单照常点击。

## 会拖慢电脑或耗电吗？

实测空载 CPU 约 0%，常驻内存约 95MB，长时间运行无增长。它做的事很少：一个每秒检查一次屏幕状态的后台计时器，加上一层不做任何渲染的黑色窗口。

## 支持 Intel 的 Mac 吗？

支持。安装包是通用二进制，同时包含 Apple 芯片和 Intel 两个版本。

## 会不会联网？会不会上传数据？

不会。应用不包含任何网络代码，不采集、不上传任何信息。详见《隐私与许可》。

## 提示"无法验证开发者"怎么办？

这是 Gatekeeper 在起作用，不是应用损坏。因为本项目没有购买 Apple 开发者账号，所以没做 Developer ID 签名与公证。

正确做法（macOS 15 及以后唯一有效的做法）：

1. 双击一次应用，看到拦截提示后点「完成」
2. 打开「系统设置 → 隐私与安全性」，向下滚到「安全性」
3. 点「仍要打开」，输入密码或触控 ID，再确认「打开」

之后系统会把它记为例外，以后双击即可。

**注意**：网上流传的「右键 → 打开」在 macOS 15 Sequoia 之后已经失效，苹果移除了这个绕过入口。另外不建议用 `xattr -d com.apple.quarantine` 或 `spctl --master-disable` 之类的命令，那是把整个系统的防护关掉，代价太大。

## 切换分辨率后黑边没了？

正常。如果内置屏切换到了"刘海下方"的分辨率档，系统本身就把刘海区域涂黑了，我们不需要再画；切回原来的分辨率会自动恢复。

## 升级系统后失效了怎么办？

macOS 大版本更新可能调整菜单栏的实现方式。如果发现黑边位置不对或消失，先退出应用重新打开；仍不正常的话，用 `--selftest` 模式跑一次自检并把输出反馈给开发者：

```bash
"/Applications/干掉刘海.app/Contents/MacOS/NotchBlack" --selftest
```
